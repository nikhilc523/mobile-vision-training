COMMON ISSUES & FIXES:
----------------------

Issue 1: "Valid keypoints: 0/34" (YOLO not detecting)
Fix: 
- Check YOLO model loaded: yolo11n-pose_float32.tflite in assets
- Check bitmap is valid (not null, correct size)
- Check YOLO interpreter initialized correctly
- Try displaying camera preview to verify person is visible

Issue 2: No "predict() called" logs (Model inference not running)
Fix:
- Check if (frameBuffer.size == maxBufferSize) condition is met
- Check frameBuffer is accumulating (not being cleared)
- Check model interpreter is initialized

Issue 3: "Output probability: 0.0" always (Model returns 0)
Fix:
- Check FlexDelegate is initialized BEFORE Interpreter
- Check TFLite model loaded: fall_detection_model.tflite in assets
- Check input buffer format: ByteBuffer, nativeOrder(), 4 * 1 * 30 * 34 bytes
- Check keypoints are in correct format: [y, x] order, normalized [0, 1]

Issue 4: Logs show correct probability but UI doesn't update
Fix:
- Ensure runOnUiThread {} is used for UI updates
- Check TextView references are correct (tvProbability, tvStatus)
- Check UI thread is not blocked
