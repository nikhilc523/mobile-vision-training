Create: YoloPoseEstimator.kt

Key requirements:

1. Load YOLO11-Pose TFLite model from assets
   - Model name: "yolo11n-pose.tflite"
   - Input size: 640×640
   - Use GPU delegate if available

2. extractKeypoints(bitmap: Bitmap): FloatArray
   - Input: Camera frame (Bitmap, any size)
   - Output: FloatArray(34) - 17 keypoints × 2 (y, x)
   
3. preprocessImage(bitmap: Bitmap): ByteBuffer
   - Resize to 640×640
   - Normalize RGB to [0, 1]
   - Return ByteBuffer (1, 640, 640, 3)

4. parseOutput(outputBuffer: ByteBuffer): FloatArray
   - YOLO output: (1, 56, 8400)
   - 56 = 4 (bbox) + 1 (obj) + 1 (class) + 17×3 (keypoints)
   - Find detection with highest confidence
   - Extract 17 keypoints × 3 (x, y, conf)
   - Filter by confidence > 0.3
   - Convert to [y, x] format (NOT [x, y]!)
   - Normalize to [0, 1]
   - Return FloatArray(34)

5. close() - Clean up interpreter and GPU delegate

4.2: Create RealKeypointAnalyzer (replace DummyKeypointAnalyzer)

```kotlin
private inner class RealKeypointAnalyzer : ImageAnalysis.Analyzer {
    private var frameCount = 0
    
    override fun analyze(image: ImageProxy) {
        try {
            // Convert ImageProxy to Bitmap
            val bitmap = image.toBitmap()
            
            // Extract real keypoints using YOLO
            val keypoints = yoloPose.extractKeypoints(bitmap)
            
            // Process frame (existing method)
            processFrame(keypoints, frameCount++)
            
        } catch (e: Exception) {
            Log.e(TAG, "Error analyzing frame", e)
        } finally {
            image.close()
        }
    }
}

// Helper: Convert ImageProxy to Bitmap
private fun ImageProxy.toBitmap(): Bitmap {
    val buffer = planes[0].buffer
    val bytes = ByteArray(buffer.remaining())
    buffer.get(bytes)
    return BitmapFactory.decodeByteArray(bytes, 0, bytes.size)
}
```

```kotlin
private fun startCamera() {

        val cameraSelector = CameraSelector.DEFAULT_BACK_CAMERA
        
        try {
            cameraProvider.unbindAll()
            cameraProvider.bindToLifecycle(
                this,
                cameraSelector,
                preview,
                imageAnalyzer
            )
            Log.d(TAG, "✅ Camera started with YOLO")

            Log.e(TAG, "Camera binding failed", e)
        }
```

⚠️ KEYPOINT FORMAT (MUST MATCH TRAINING!)

YOLO output: [x, y, conf] for each keypoint
Training format: [y, x] for each keypoint

YOU MUST SWAP x,y → y,x!

Example:
```kotlin
// YOLO gives: x=0.5, y=0.3, conf=0.9
// You must store: keypoints[i*2] = 0.3 (y first!)
//                 keypoints[i*2+1] = 0.5 (x second!)
```

⚠️ NORMALIZATION

All values MUST be in [0, 1] range:
- y: 0 = top of image, 1 = bottom
- x: 0 = left of image, 1 = right

⚠️ CONFIDENCE FILTERING

Only use keypoints with confidence > 0.3:
```kotlin
if (conf > 0.3f) {
    keypoints[i*2] = y
    keypoints[i*2+1] = x
} else {
    keypoints[i*2] = 0f
    keypoints[i*2+1] = 0f
}
```

⚠️ GPU DELEGATE

Use GPU if available for faster inference:
```kotlin
val compatList = CompatibilityList()
if (compatList.isDelegateSupportedOnThisDevice) {
    val gpuDelegate = GpuDelegate(compatList.bestOptionsForThisDevice)
    options.addDelegate(gpuDelegate)
}
```

YOLO OUTPUT FORMAT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

YOLO11-Pose output shape: (1, 56, 8400)

For each of 8400 detections:
- Index 0-3: Bounding box [x, y, w, h]
- Index 4: Object confidence
- Index 5: Class confidence
- Index 6-56: 17 keypoints × 3 values [x, y, conf]

Keypoint order (COCO format):
0: nose, 1: left_eye, 2: right_eye, 3: left_ear, 4: right_ear,
5: left_shoulder, 6: right_shoulder, 7: left_elbow, 8: right_elbow,
9: left_wrist, 10: right_wrist, 11: left_hip, 12: right_hip,
13: left_knee, 14: right_knee, 15: left_ankle, 16: right_ankle

Processing steps:
1. Loop through 8400 detections
2. Find detection with highest confidence
3. Extract 17 keypoints from that detection
4. For each keypoint:
   - Get x, y, conf
   - If conf > 0.3: normalize and swap to [y, x]
   - If conf ≤ 0.3: set to [0, 0]
5. Return FloatArray(34)
